Technical reference for developers and audio engineers.

Environment & API Authentication

VOXA implements a security-first architecture. Your ElevenLabs credentials can be provided via server-side environment variables in .env.local as ELEVENLABS_API_KEY, or stored securely in your client browser via the Studio Settings panel. Keys are never logged or exposed in client bundles.

# .env.local
ELEVENLABS_API_KEY=sk_...
PORT=3000
